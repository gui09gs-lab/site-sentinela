# Glossário

## Projeto
| Termo | Significado |
|---|---|
| Sentinela | Nome provisório da marca do cliente (fictício) |
| prévia / modo prévia | Versão de demonstração com `preview.js` (aviso, marca-d'água, envios bloqueados, noindex) |
| Opção 1 "Confiança" | Layout claro e corporativo moderno — **escolhido**, hoje é o `index.html` |
| Opção 2 "Central ao vivo" | Layout escuro com painel de 4 câmeras ao vivo, log de eventos e app no celular |
| Opção 3 "Editorial" | Tipografia gigante condensada, creme e vermelho, faixa animada, foto no hover |
| simulador | `simulador.html`: planta + câmeras + cobertura + pontos cegos |
| briefing | Questionário de personalização para o cliente (doc, planilha e script do Forms) |
| v1 / versão 3D | Primeira versão com câmera 3D em canvas; descartada, está no histórico do git |
| VELA | Briefing original (anel cerâmico em 3D com vídeos) usado como base da v1 |
| Almeida Segurança | Projeto anterior citado pelo usuário como inspiração; nunca encontrado |
| Sekron | sekrondigital.com.br — referência de estilo e tom (vermelho/branco, blocos de números, linguagem formal) |

## Segurança eletrônica
| Termo | Significado |
|---|---|
| CFTV | Circuito fechado de TV (sistema de câmeras) |
| Bullet (canhão) | Câmera tubular externa, IP67, lente fixa, 53–98° |
| Dome | Câmera de cúpula, discreta, interna, 80–110°+ |
| Speed Dome / PTZ | Pan-Tilt-Zoom: esférica motorizada, gira 360°, zoom óptico |
| Panorâmica / olho de peixe / 360° | Dome achatada no centro do teto, cobre tudo |
| IP67 | Proteção contra poeira e água (uso externo) |
| IR | Infravermelho (visão noturna) |
| Starlight | Sensor que mantém cor com pouca luz |
| DVR / NVR | Gravador de câmeras analógicas / IP |
| PoE | Energia e dados pelo mesmo cabo de rede |
| comodato | Equipamento emprestado mediante contrato/mensalidade |

## Técnico
| Termo | Significado |
|---|---|
| all-intra | Vídeo em que todo quadro é keyframe (permite scrub suave com o scroll) |
| wa.me | Link do WhatsApp com mensagem pronta (`?text=`) |
| LGPD | Lei Geral de Proteção de Dados |
| noindex | Meta que pede aos buscadores para não indexar |
| registro.br | Registro de domínios `.br` |
